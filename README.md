# 大盗五右卫门 - 机关道中 (1987, Konami) 反汇编及汉化（256 KiB 扩容版）

## 游戏信息
- Ganbare Geomon (大盗五右卫门 - 机关道中)
  https://generation-msx.nl/software/konami/ganbare-goemon/923

## 构建

使用 SjASMPlus 1.24 或更新版本：

```sh
make            # 生成 out/ganbare.rom（256 KiB）
make run        # 在 openMSX 中运行（自动静音）
make clean      # 清理 out/ 与 TAGS
```
